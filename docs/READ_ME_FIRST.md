# RUDRA: read me first

RUDRA turns SDR stills and footage into scene-referred HDR masters.

## Start

1. Open RUDRA, then **File › Open…** (or drop files on the window): a still, a
   folder of frames, or a movie.
2. **1 Look**: set Exposure, Strength and your display's peak. Hold **B** for the
   original SDR; **W** shows a wipe (SDR left, RUDRA right).
3. **2 Check**: peak, average light, light above SDR white, out-of-P3 share and
   the scopes. **Invented pixels** shows what RUDRA made up.
4. **3 Deliver**: Grading master (ACES EXR), HDR10 movie, Broadcast HDR (HLG), or
   Custom… for every other format.

## The learned model

Optional and free: **Look › Download the model…** or **File › Model packages…**.
Each file is checked before it is used. AI fill is experimental and off by
default; review every frame it touches.
